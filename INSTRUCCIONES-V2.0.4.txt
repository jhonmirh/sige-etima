SIGE-ETIMA V2.0.4 — MENCIONES DE EDUCACIÓN MEDIA TÉCNICA

1. Abra PowerShell.
2. Ejecute:
   cd C:\sige-etima
   docker compose stop api web

3. Descomprima SIGE-ETIMA-V2.0.4-MENCIONES-PARCHE.zip.
4. Copie EL CONTENIDO INTERNO de la carpeta SIGE-ETIMA-V2.0.4-PARCHE sobre C:\sige-etima y acepte reemplazar.

5. Reconstruya:
   docker compose build api web

6. Levante:
   docker compose up -d --force-recreate api web

7. Revise:
   docker compose ps

Esperado:
   db   Up (healthy)
   api  Up
   web  Up

8. Abra http://localhost:3000 y haga Ctrl + F5.

IMPORTANTE
- NO use docker compose down -v.
- Esta versión añade la tabla Mention y campos opcionales de mención en Section.
- El arranque normal del API ejecuta prisma db push y luego seed.
- El seed registra CIENCIAS AGRÍCOLAS Y PECUARIAS para el plan 41049 y vincula a esa mención las secciones técnicas anteriores que todavía no tenían mención.
- No se eliminan estudiantes, representantes, matrículas, notas ni números de lista.

PRUEBA RÁPIDA
A) Matrícula > Configuración anual.
B) Como ADMIN, verifique "Catálogo de menciones".
C) Debe aparecer CIENCIAS AGRÍCOLAS Y PECUARIAS para el plan 41049 después de que el API ejecute el seed.
D) Cree una sección técnica: debe exigir mención.
E) En Primera matrícula, al escoger 41049 debe aparecer Mención.
F) En Reinscripción de un estudiante técnico, la mención anterior debe aparecer de solo lectura y solo deben listarse secciones de esa misma mención.
