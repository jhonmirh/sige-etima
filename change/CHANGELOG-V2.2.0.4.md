# SIGE-ETIMA V2.2.0.4 — Portada responsive de acceso

- Se integran las dos imágenes entregadas por el usuario en la página real de login.
- En escritorio se muestran simultáneamente en una galería vertical de alta presencia visual.
- En tablets y teléfonos la galería se transforma en un carrusel horizontal táctil con scroll-snap; las imágenes ya no se ocultan.
- Se mantiene el escudo institucional en el panel de acceso.
- El botón «Entrar al sistema» ahora ofrece respuesta visual inmediata al clic: presión, brillo, estado deshabilitado, spinner y texto «Entrando al sistema…».
- Se evita el doble envío mientras la autenticación está en proceso.
- Se añade mensaje de conexión si el API no está disponible.
- Sin cambios en API, Prisma ni PostgreSQL.
