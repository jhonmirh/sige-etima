# Validaciones antes de producción

El sistema entrega la estructura integral y las reglas expresadas en la narrativa. Antes de ponerlo en producción deben validarse institucionalmente estos puntos que la fuente no define de forma inequívoca:

1. Fórmula exacta de definitiva de lapso y definitiva anual (ponderación entre evaluaciones/lapsos).
2. Umbral cuantitativo oficial de aprobación para todas las asignaturas.
3. Catálogo oficial completo Estado → Municipio → Parroquia que utilizará la institución. El esquema y API están listos; el seed incluido trae las 24 entidades federales, pero no inventa municipios/parroquias que no estaban listados en la narrativa.
4. Catálogo formal de tallas de pantalón y camisa; el modelo acepta el conjunto institucional y la UI puede transformarse a selector parametrizado.
5. Texto final jurídico/administrativo de las constancias, firmas, sellos y ubicación exacta de logos.
6. Política de conservación de documentos digitalizados y permisos de privacidad.
